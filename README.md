# Start Help ❤️

O **Start Help** é um sistema de assistência de emergência e gerenciamento de cuidados voltado para cuidadores de idosos e crianças. O projeto integra uma interface moderna e responsiva com um back-end robusto e persistência em banco de dados.

## 🛠️ Tecnologias Utilizadas

* **Front-end:** React (Vite), JavaScript (JSX), CSS3
* **Back-end:** Spring Boot (Java 21), Spring Data MongoDB
* **Banco de Dados:** MongoDB (Porta 27017)

## 📦 Estrutura do Repositório

* `/starthelp-front`: Código-fonte do front-end em React.
* `/starthelp`: Código-fonte da API back-end em Spring Boot.

## 🚀 Como Executar o Projeto

### Pré-requisitos
* Node.js instalado
* Java 21 instalado
* Serviço do MongoDB ativo localmente na porta `27017`

### 1. Rodando o Back-end (Java)
Navegue até a pasta do back-end e execute o Spring Boot:
```bash
cd starthelp
./mvnw spring-boot:run
